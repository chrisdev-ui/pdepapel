# Negocio y crecimiento

## Para qué sirve

La pantalla **Ventas → Negocio y crecimiento** ayuda a tomar decisiones mensuales con ventas registradas, utilidad estimada, gastos que anotes y una propuesta de distribución. También indica qué productos conviene preparar para contenido o una prueba de difusión en Instagram o TikTok.

No mueve dinero, no modifica pedidos, no cambia inventario, no presenta impuestos y no crea anuncios externos. El banco, Mercado Pago, Meta y TikTok siguen siendo la fuente final de cada movimiento real.

## Revisión semanal de dinero

1. Entra a **Ventas → Negocio y crecimiento** y pulsa **Actualizar datos**.
2. Revisa **Ventas netas registradas** y **Utilidad operativa estimada**. Esta última depende de que los productos tengan costo de compra correcto.
3. En **Caja y distribución**, define una reserva operativa, la reserva para impuestos, el porcentaje de reinversión y el porcentaje máximo de retiro personal. Reinversión y retiro juntos no pueden superar 100 %.
4. Pulsa **Guardar reglas**. El valor de **Retiro personal sugerido** es una guía; compara siempre con el saldo real del banco antes de retirar.
5. Registra los movimientos reales del mes con el botón **Registrar**. Puedes editarlos o eliminarlos si anotaste uno por error.

## Qué movimiento registrar

| Situación real | Tipo que debes elegir | Ejemplo |
| --- | --- | --- |
| Empaques, mensajería, arriendo o servicios | Gasto operativo | `Empaques para pedidos de agosto` |
| Cobro real de una campaña o impulso | Inversión en marketing | `Impulso de Instagram, semana 2` |
| Pago hecho a impuestos | Pago de impuestos | `Anticipo tributario de agosto` |
| Dinero usado para comprar mercancía | Compra o reposición de inventario | `Compra de cuadernos, factura 432` |
| Dinero que la dueña sacó para uso personal | Retiro personal | `Retiro personal de agosto` |
| Dinero personal puesto en el negocio | Aporte personal al negocio | `Aporte para nueva colección` |

Una compra de inventario se muestra por separado: no se descuenta otra vez de la utilidad porque el costo del producto ya se descuenta cuando se vende. Aun así, debes anotarla para recordar el compromiso real de caja. No registres una misma salida dos veces, por ejemplo como compra de inventario y como gasto operativo.

## Cómo preparar contenido o una campaña

1. En **Campañas sociales**, mira primero el estado de cada producto:
   - **Lista para prueba:** tiene margen, stock, ficha completa y ventas recientes.
   - **Primero orgánico:** publica contenido sin pagar y revisa si genera interés antes de invertir.
   - **No promocionar aún:** primero repón stock, completa la ficha o registra el costo.
2. Pulsa **Preparar borrador** en el producto elegido.
3. Revisa el canal, objetivo, idea de contenido y presupuesto máximo. El presupuesto es un tope para planear; no cobra nada.
4. Pulsa **Guardar borrador**.
5. Desde el borrador, pulsa **Copiar enlace** y úsalo al crear el post, historia, video o anuncio externo. El enlace tiene medición UTM para reconocer la campaña en Analytics.
6. Cuando pagues realmente una difusión, vuelve a **Caja y distribución** y registra el valor como **Inversión en marketing**.

Ejemplo: si el panel propone COP 30.000 para una prueba de un cuaderno, guarda el borrador, publica un reel con el enlace copiado y fija en Meta o TikTok un límite máximo de COP 30.000. Si finalmente la plataforma cobra COP 24.500, registra COP 24.500 como inversión real.

## Antes de confiar en una recomendación

- Completa el costo de compra de cada producto. Un producto sin costo no se recomienda para pauta pagada.
- Verifica fotos, descripción, precio y stock físico.
- No promociones un producto con inventario bajo o próximo a agotarse.
- Una campaña con visitas no garantiza utilidad: compara ventas, costo de productos, valor cobrado por la plataforma, envíos y devoluciones.
- Para impuestos, usa siempre **Reportes tributarios** y consulta al contador. Este panel no reemplaza ese documento.

## Instagram y TikTok: siguiente integración

Hoy los borradores son intencionalmente manuales y seguros: no publican ni gastan. La conexión futura se hará por autorización de la cuenta propietaria, no con contraseñas guardadas en P de Papel.

Antes de conectar una plataforma, la propietaria necesitará tener:

- **Instagram/Meta:** cuenta profesional de Instagram vinculada a una página de Facebook y a un portafolio comercial con la cuenta publicitaria correcta.
- **TikTok:** cuenta Business, acceso al Business Center y una aplicación aprobada para las funciones que se quieran usar.
- Una persona autorizada para confirmar qué cuenta, presupuesto y permisos permite. Nunca se debe conectar una cuenta personal de un colaborador.

Cuando esa etapa se implemente, se pedirá autorización OAuth, se mostrará la cuenta conectada y cada creación, pausa o cambio de presupuesto seguirá requiriendo una confirmación explícita dentro de P de Papel.
