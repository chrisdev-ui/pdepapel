# Arreglar el inventario después de una feria anterior

Usa esta guía cuando ya registraste las ventas de una feria como pedidos y solo necesitas que las cantidades de los productos queden iguales a lo que realmente tienes.

## Antes de empezar

- Hazlo en un momento tranquilo, cuando nadie más esté cambiando cantidades de productos.
- Ten a la mano todos los productos que quedaron después de la feria.
- Cuenta solo los productos que todavía puedes vender. No cuentes muestras dañadas, regalos entregados ni productos apartados para otra actividad.
- Si vendiste cápsulas sorpresa, cuenta el producto que quedó dentro de cada cápsula. No necesitas una hoja por cápsula: cada producto se cuenta junto con los demás iguales.
- Esta herramienta **no crea ventas ni cambia pedidos**. Solo arregla las cantidades de productos.

## Paso a paso

1. Entra al panel y abre **Movimientos de Inventario**.
2. Pulsa **Conciliar feria anterior**.
3. Pulsa **Descargar plantilla**. Siempre descarga una nueva el mismo día en que vas a hacer el conteo.
4. Abre el archivo descargado. Lee primero la pestaña **LEEME**.
5. Ve a la pestaña **CONCILIACIÓN**. No cambies las celdas grises.
6. En cada fila escribe, en la celda verde de **Conteo físico disponible**, cuántas unidades de ese producto realmente quedaron.
7. Si el número es diferente al que aparece como **Stock sistema**, elige una **Causa**. Por ejemplo:
   - **Venta presencial ya registrada**: se vendió en la feria y ese pedido ya fue registrado.
   - **Daño**: el producto se dañó y no se puede vender.
   - **Pérdida**: el producto no aparece y no sabes dónde quedó.
   - **Promoción/obsequio**: se entregó como regalo.
   - **Uso interno**: se usó para el negocio.
   - **Compra no registrada**: encontraste unidades nuevas que todavía no habías anotado.
8. Escribe una nota corta si te ayudará a recordar el caso. Por ejemplo: “Feria del Parque, mesa 2”.
9. Cuando revises una fila con calma, elige **Revisado**.
10. Solo después de estar segura, elige **Sí** en **Autorizar carga**. Deja vacío ese campo si no quieres cambiar esa fila.
11. Guarda el archivo en Excel.
12. Vuelve al panel, selecciona el archivo y pulsa **Revisar archivo**.
13. Lee el resumen. Debe mostrar **0 con errores**. Si aparece un error, no apliques nada: corrige el archivo o descarga una plantilla nueva y vuelve a contar.
14. Revisa la lista de cambios que se aplicarán. Si todo coincide con tu conteo, pulsa **Aplicar ajustes** y confirma.
15. Espera el mensaje de éxito. Luego revisa **Movimientos de Inventario**: allí quedará guardado cada cambio.

## Si algo no sale bien

- **Dice que el inventario cambió:** alguien hizo un cambio después de descargar el archivo. Descarga una plantilla nueva y vuelve a revisar solo las filas necesarias.
- **Dice que hay una feria activa:** no uses esta herramienta para ese producto. Termina primero la feria activa desde el módulo de ferias.
- **No aparece un kit:** es normal. Cuenta los productos que hacen parte del kit; el panel calcula el kit solo.
- **Te equivocas antes de aplicar:** no pasa nada. Cierra la ventana, corrige el archivo y vuelve a revisarlo.
- **Te equivocas después de aplicar:** no vuelvas a subir el mismo archivo. Usa **Ajustar Inventario** y deja una nota explicando la corrección.
